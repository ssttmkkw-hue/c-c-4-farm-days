# Farm Days / 牧场日常

A cozy, Harvest Moon–inspired farming life sim with simpler farming than Stardew Valley.

一款受《牧场物语》启发的温馨农场生活游戏，种地比《星露谷》更简单。

This repo is just getting started. Playable v1 will land shortly.

本仓库刚创建，可玩的第一版很快会提交上来。

## Run / 运行

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

然后打开 `http://localhost:8000`。
